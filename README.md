# 🤖 Личный ИИ-ассистент в Telegram

Бот-помощник на Go с ИИ [DeepSeek](https://platform.deepseek.com): напоминания, расписание, заметки и обычный разговор на любые темы. Работает на ПК, сервере и **прямо на телефоне в Termux**.

## Возможности

- 🗣 **Понимает обычный язык.** «Напомни завтра в 9 позвонить маме», «каждый вторник в 19:00 бассейн, напоминай за час», «перенеси встречу на 16:00», «что у меня в пятницу?».
- ⏰ **Напоминает заранее.** У каждого события может быть несколько уведомлений («за день и за час»). Повторы: каждый день, по будням, каждую неделю, раз в N недель, каждый месяц, каждый год, с датой окончания.
- 📎 **Читает расписание из файлов**: `.xlsx`, `.docx`, `.txt`, `.csv` (а также `.md`, `.ics` и другие текстовые). ИИ находит события, показывает список, и после нажатия «✅ Добавить все» ставит напоминания. В подписи к файлу можно уточнить: «напоминай за 10 минут», «только пары по понедельникам».
- 📝 **Заметки**: «запомни: код домофона 1234», потом «какой код домофона?».
- 🔘 **Кнопки под напоминанием**: «✅ Готово», «⏰ 15 мин», «⏰ 1 час», «⏰ Завтра».
- ☀️ **Утренняя сводка** с планом на день (время настраивается).
- 💬 **Не только напоминалка**: можно обсудить любой вопрос, попросить совет, текст, перевод. Бот помнит контекст беседы.
- 🧩 **Работает и без ИИ**: команды `/remind 30m текст`, `/list`, `/today`, `/note` не зависят от DeepSeek.
- 🔒 **Личный**: отвечает только вам (по Telegram ID).
- 📶 **Устойчив к плохой сети**: если телефон был без интернета или «спал», уведомления не теряются и приходят с пометкой «пропущенное».

## Быстрый старт

### 1. Нужны два ключа

1. **Токен бота.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен вида `123456789:AA…`.
2. **Ключ DeepSeek.** Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com), пополните баланс и создайте ключ в разделе *API Keys*.

### 2а. Запуск на Android (Termux)

1. Установите **Termux** из [F-Droid](https://f-droid.org/packages/com.termux/) или [GitHub](https://github.com/termux/termux-app/releases). Версия из Google Play устарела и не подходит.
2. В Termux:

```bash
pkg install -y git
```

```bash
git clone https://github.com/kkazantsevrv/ai-assistent.git
```

```bash
cd ai-assistent && bash scripts/termux-install.sh
```

Скрипт поставит Go, соберёт бота, создаст файл `.env` и предложит включить автозапуск.

3. Впишите токены (в nano: сохранить — `Ctrl+O`, `Enter`, выйти — `Ctrl+X`):

```bash
nano .env
```

4. Запустите бота в фоне:

```bash
bash scripts/start.sh
```

5. Напишите своему боту в Telegram `/start`. Первый, кто напишет, станет владельцем. Чтобы закрепить доступ, отправьте боту `/id` и впишите свой ID в `ALLOWED_USER_IDS` в `.env`.

Управление: `bash scripts/logs.sh` (журнал), `bash scripts/stop.sh` (остановить), `bash scripts/start.sh` (запустить).

> **Чтобы Android не «убивал» бота:**
> - Настройки → Приложения → Termux → Батарея → **Без ограничений**.
> - Скрипт запуска сам включает `termux-wake-lock`. Уведомление Termux в шторке должно оставаться.
> - Автозапуск после перезагрузки: приложение [Termux:Boot](https://f-droid.org/packages/com.termux.boot/), его включает `termux-install.sh`.
> - Android 12+ может закрывать фоновые процессы («phantom process killer»). На Android 14+ это отключается в настройках разработчика («Отключить ограничения дочерних процессов»). На 12–13 — через `adb shell device_config put activity_manager max_phantom_processes 2147483647`.

<details>
<summary>Вариант без сборки на телефоне</summary>

На ПК с Go выполните `make android` (или `GOOS=android GOARCH=arm64 CGO_ENABLED=0 go build -o assistant .`). Скопируйте `dist/assistant-android-arm64` на телефон и в Termux положите его в папку проекта под именем `assistant`:

```bash
cp /sdcard/Download/assistant-android-arm64 ~/ai-assistent/assistant && chmod +x ~/ai-assistent/assistant
```

Запускать файл прямо из `/sdcard` нельзя: Android запрещает там исполнение.
</details>

### 2б. Запуск на ПК или сервере

Нужен Go 1.24 или новее.

```bash
git clone https://github.com/kkazantsevrv/ai-assistent.git && cd ai-assistent
```

```bash
cp .env.example .env
```

После этого впишите токены в `.env` и выполните:

```bash
go build -o assistant . && ./assistant
```

На Linux-сервере можно запускать в фоне через `bash scripts/start.sh` или оформить systemd-службу.

## Как пользоваться

Просто пишите боту, как живому секретарю:

| Вы пишете | Что произойдёт |
|---|---|
| «Напомни через 20 минут выключить духовку» | Уведомление через 20 минут |
| «Завтра в 15:00 стоматолог» | Событие + напоминание за 15 мин (по умолчанию) |
| «По будням в 7:30 зарядка» | Повтор по будням |
| «Каждый понедельник и четверг в 19:00 английский, напоминай за час» | Два еженедельных события |
| «Платёж за интернет 5 числа каждого месяца» | Ежемесячное напоминание |
| «Что у меня на этой неделе?» | Расписание с учётом повторов |
| «Перенеси стоматолога на пятницу» / «удали английский» | Изменение / удаление |
| «Запиши: размер обуви у сына — 34» | Заметка |
| «Напоминай о парах за 30 минут» | Меняет все события расписания «Пары» |
| «Я теперь живу в Новосибирске» | Меняет часовой пояс |
| «Объясни, как работает ипотека» | Обычный разговор |

Если ответить (reply) на сообщение-напоминание, например «перенеси на час позже», бот поймёт, о каком напоминании речь.

**Файлы.** Пришлите таблицу или документ с расписанием (пары, смены, тренировки, график дежурств). Дни недели без дат станут еженедельными событиями, конкретные даты станут разовыми. Объединённые ячейки Excel и кодировку Windows-1251 бот понимает. Старые `.xls`/`.doc` пересохраните в `.xlsx`/`.docx`. Если в файле нет расписания, бот просто перескажет его и ответит на вопросы о нём.

### Команды

| Команда | Описание |
|---|---|
| `/today`, `/tomorrow`, `/week` | План на сегодня / завтра / 7 дней |
| `/list` | Все активные напоминания с кнопками-командами `/done_N`, `/del_N` |
| `/remind 30m текст` | Быстрое напоминание без ИИ. Форматы: `30m`, `2h`, `1h30m`, `1д`, `18:30`, `завтра 9:00`, `25.12 10:00`, `2026-12-31 23:00` |
| `/notes`, `/note текст` | Заметки |
| `/settings` | Настройки |
| `/tz Europe/Moscow` или `/tz +5` | Часовой пояс |
| `/before 30` | За сколько минут напоминать о событиях |
| `/digest 07:30` или `/digest off` | Утренняя сводка |
| `/reset` | Забыть историю диалога (напоминания остаются) |
| `/export` | Выгрузить все данные в JSON |
| `/id` | Показать свой Telegram ID |

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | **Обязательно.** Токен от @BotFather |
| `DEEPSEEK_API_KEY` | — | Ключ DeepSeek. Без него работают только команды |
| `ALLOWED_USER_IDS` | пусто | Кому отвечать (ID через запятую). Если пусто, владельцем станет первый написавший |
| `TIMEZONE` | `Europe/Moscow` | Часовой пояс по умолчанию |
| `DEFAULT_REMIND_BEFORE` | `15` | Минут до события для уведомления |
| `DAILY_DIGEST_TIME` | `08:00` | Время утренней сводки или `off` |
| `DEEPSEEK_MODEL` | `deepseek-chat` | `deepseek-chat` (быстрее, рекомендуется) или `deepseek-reasoner` |
| `DEEPSEEK_TEMPERATURE` | `0.7` | «Креативность» ответов |
| `HISTORY_LIMIT` | `30` | Сколько последних сообщений диалога помнить |
| `DATA_DIR` | `./data` | Папка с данными |
| `TELEGRAM_API_URL` | `https://api.telegram.org` | Свой Bot API-сервер или прокси |
| `DNS_SERVERS` | авто | DNS, если в Termux не резолвятся адреса (`1.1.1.1,8.8.8.8`) |

Переменные окружения имеют приоритет над `.env`. Путь к файлу настроек можно задать флагом: `./assistant -env /path/to/.env`. Стандартные `HTTPS_PROXY`/`HTTP_PROXY` тоже учитываются.

## Данные

Всё хранится в одном файле `data/store.json`: напоминания, заметки, настройки и история диалога. Запись атомарная, а при запуске создаётся копия `store.json.bak`. Для резервной копии достаточно скопировать папку `data/` или нажать `/export`. Чтобы перенести бота с ПК на телефон, скопируйте `data/` и `.env`.

## Устройство проекта

```
main.go                      точка входа
internal/config              загрузка .env и переменных окружения
internal/telegram            клиент Telegram Bot API (без сторонних библиотек)
internal/llm                 клиент DeepSeek (OpenAI-совместимый, вызов функций)
internal/storage             хранилище в JSON
internal/schedule            повторы, срабатывание уведомлений (чистая логика + тесты)
internal/fileparse           извлечение текста из txt/csv/docx/xlsx
internal/bot                 команды, диалог с ИИ, инструменты, импорт файлов, планировщик
internal/netfix              DNS и сертификаты для Termux/Android
scripts/                     установка и запуск в Termux
```

ИИ управляет напоминаниями через **вызов функций**: `add_reminder`, `get_schedule`, `update_reminder`, `delete_reminders`, `add_note` и другие. Модель не «придумывает», что поставила напоминание: бот подтверждает только реально выполненные действия. Каждый запрос получает текущую дату, календарь на две недели и список ближайших дел, поэтому «в следующую пятницу» и «послезавтра» понимаются правильно.

Ни CGO, ни внешних баз данных нет, поэтому одна и та же сборка работает везде. Из сторонних зависимостей только [excelize](https://github.com/xuri/excelize) для Excel и `golang.org/x/text` для кодировок.

```bash
make test      # тесты
```

```bash
make dist      # бинарники для Android, Linux, Windows, macOS
```

## Решение проблем

- **`Telegram отклонил токен`**: проверьте `TELEGRAM_BOT_TOKEN`.
- **`конфликт — запущена другая копия бота`**: бот с этим токеном уже работает в другом месте (например, и на ПК, и на телефоне). Остановите лишнюю копию.
- **`DeepSeek: недостаточно средств` / `неверный API-ключ`**: пополните баланс или проверьте ключ.
- **В Termux `lookup api.telegram.org … connection refused`**: пропишите `DNS_SERVERS=1.1.1.1,8.8.8.8` в `.env`.
- **Напоминания приходят не в то время**: проверьте часовой пояс в `/settings`.
- **Бот перестаёт отвечать, когда экран выключен**: см. блок «Чтобы Android не убивал бота» выше.
